# 宿主目录

发布顺序是 Codex 首版、DSH 第二版。按宿主保存接入文件，不复制一套运行源码来表示一个新版本。

| 目录 | 当前状态 | 内容 |
|---|---|---|
| [codex](codex/README.md) | 已实现，0.1.0 | 插件清单、四项同步 hooks、安装说明和打包用 marketplace 配置 |
| [dsh](dsh/README.md) | 规划 | 接口待确认，尚无运行入口或安装包 |

Go 运行源码暂留仓库根目录；其中仍包含当前 Codex 事件协议。DSH 接入时依据实际接口增加必要适配，复用授权规则和命令识别，不预先发明通用协议或第二份实现。

当前打包命令仅生成 Codex 包到 `dist/codex/`；DSH 实现后使用自己的产物目录 `dist/dsh/`。版本号以各宿主自己的清单为准，发布阶段不自动改变现有版本号。
